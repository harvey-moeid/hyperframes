---
title: "HTML contract checklist"
description: "A one-page checklist of the composition contract, for a quick pass before you render."
---

Use this as a fast pre-render check. For the full attribute reference see
[HTML schema reference](/reference/html-schema); for what `lint` and `check`
report, see [Lint rules](/reference/lint-rules).

## Timing

- Every timed element has `class="clip"`, `data-start`, and `data-duration` in
  seconds, and shows over `[start, start + duration)`. Land an end state just
  before its end, never exactly on it.
- The video's length is the root's `data-duration`. Raise it whenever you add a
  clip that ends later, or the new clip never plays.
- Each composition builds one paused timeline and registers it **after**
  adding its tweens: `window.__timelines["<data-composition-id>"] = tl`.
- Use `gsap.fromTo`, not `.from`, inside a scene file. The host re-seeks the
  scene every time it shows, and `.from` only records its start state once.

## Determinism

- No `Date.now()`, unseeded `Math.random()`, network fetches, timers, or
  `repeat: -1`. Everything visible must be a function of timeline time, or the
  same input won't produce the same frames.

## Animation

- Never tween `display`, `visibility`, or `autoAlpha` on a `.clip` — animate a
  child element instead.
- No CSS `transform` on an element GSAP already transforms. Animate the
  transform itself, not `left` / `top` / `width` / `height`.

## Media

- Never `play()`, `pause()`, or seek media imperatively.
- A `<video>` with its own sound: `data-has-audio="true"`. Silent footage:
  `muted`. Music, voiceover, replacement sound, and J/L cuts are a separate
  `<audio>`.
- Every `<audio>` needs an `id` or it is silently left out of the mix.
- Never put `crossorigin` on a media element.
- Time the `<video>` tag itself, never its wrapper.

## Fonts and assets

- Only the bundled fonts resolve by name. Any other family needs `@font-face`
  pointing at a file under `assets/fonts/`.
- Asset paths are relative — `assets/...`, never a leading `/` — in
  sub-compositions too.

## Looks and treatments

- Grades, grain, blur, and vignettes on footage go through
  `npx hyperframes media-treatment`, never a CSS filter.

## File structure

- A scene file's styles, markup, and script live inside `<template>`; style
  its root as `#root`.
- Intended overflow or overlap gets `data-layout-allow-overflow` or
  `data-layout-allow-overlap` — plain `overflow: hidden` does not silence the
  layout audit.

## Keep it editable

- One scene per sub-composition, with short, stable, readable IDs. The root
  holds only scene hosts, media, and audio.
- Timed elements are written in HTML, not generated by script, each with a
  stable `id`.
- Copy, brand colors, and swappable media are variables: `data-var-text`,
  `data-var-src`, `var(--id)`.
- One kind per track: `data-track-kind="graphics"` on scene and overlay hosts,
  `"captions"` on the single host that holds every caption group.
- Content stays inside the 90% action-safe box; captions and key text inside
  the 80% title-safe box.

## Validate

```bash
npx hyperframes check --json
```

Fix every error and weigh every warning before you render.
